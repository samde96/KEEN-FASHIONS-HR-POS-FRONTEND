# Home hero font

`caveat-latin-variable.ttf` is a Latin and punctuation subset of the Caveat variable font (weights 400–700), self-hosted for the Home hero. The rest of KEEN continues to use Space Grotesk.

Source: [Google Fonts Caveat](https://github.com/google/fonts/tree/main/ofl/caveat).

Copyright 2014 The Caveat Project Authors. Distributed under the SIL Open Font License 1.1; see [Caveat-OFL.txt](Caveat-OFL.txt).

The subset retains Latin characters U+0020–U+00FF, punctuation U+2000–U+206F, variable weights, and layout features. It was generated with locally available FontTools; FontTools is not an application dependency.
